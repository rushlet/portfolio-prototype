# Portfolio visual prototype

A design-focused, static HTML/CSS prototype for portfolio. Built with AI and intentionally separate from the future Next.js implementation.

## Open locally

Open `index.html` in a browser. No build step is required. The GEM dashboard preview is a live embedded Flourish-powered view and needs an internet connection.

## Pages

- `index.html` — responsive portfolio homepage
- `work.html` — selected case studies, published stories, hobby projects, writing and talks
- `case-study-warmer.html` and `case-study-gem.html` — long-form case study drafts
- `resume.html` — resume content from the CV

## Design direction

- Off-white canvas, navy text, cobalt outlines, pink highlights, and small yellow accents. 
- Friendly rounded controls and offset shadows draw on the GetTogether interface
- Bold typographic hero and generous spacing inspired by the Kay Stocks reference
- The layout includes visible keyboard focus, a skip link, semantic page structure, and reduced-motion handling.

This is a static design prototype, not the production portfolio or future Next.js site.
